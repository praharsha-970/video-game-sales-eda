
🎮 Video Game Sales Analysis (EDA)

📌 Project Overview

This project explores a video game sales dataset obtained from Kaggle to identify sales trends, popular game genres, top-performing publishers, and regional market preferences.

Using Exploratory Data Analysis (EDA), the project investigates how video game sales vary across North America, Europe, Japan, and other regions.

🎯 Objectives

- Analyze global video game sales and regional performance.
- Identify the best-selling video games.
- Compare sales across different game genres.
- Find publishers with the highest sales and largest game catalogs.
- Explore regional differences in gaming preferences.
- Visualize sales patterns and extract meaningful insights.

🛠️ Technologies & Tools

- Python – Programming and data analysis
- Pandas – Data cleaning, manipulation, and aggregation
- NumPy – Numerical operations
- Matplotlib – Data visualization
- Seaborn – Statistical data visualization
- Google Colab – Development environment

📊 Analysis Performed

- Data inspection and preprocessing
- Handling missing values
- Genre-wise sales analysis
- Publisher-wise sales comparison
- Regional sales analysis
- Identification of top-selling games
- Data visualization and trend exploration

📁 Dataset

The dataset contains information about video games, including:

- Game name
- Platform
- Release year
- Genre
- Publisher
- Regional sales (North America, Europe, Japan, and other regions)
- Global sales

Source: "Kaggle – Video Game Sales Dataset" (https://www.kaggle.com/datasets/gregorut/videogamesales)

💡 Key Takeaways

This project aims to uncover patterns in the video game industry by examining sales performance across genres, publishers, and geographical regions.

The analysis helps understand which games and publishers perform well globally and how gaming preferences differ between markets.

🚀 How to Run

1. Clone or download this repository.
2. Open "video_game_sales1.ipynb" in Google Colab or Jupyter Notebook.
3. Download the dataset from Kaggle.
4. Upload the dataset to your environment.
5. Run the notebook cells to reproduce the analysis.
